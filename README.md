# PostureDetection

I have uploaded my Posture Detection System - Single layer PCB Design 
Designed a single-layer PCB integrating BMI160 6-axis IMU, MAX98357A I2S audio amplifier, AP2112K-3.3 LDO regulator, and a 3.7V Li-Po supply — optimised for a compact wearable form factor modelled as Bluetooth headphones.
Implemented real-time gyroscopic posture classification using BMI160 sensor data, triggering audio feedback via I2S interface whenever deviation thresholds were exceeded.
Integrated Bluetooth connectivity with a companion Android application for continuous posture alerts and session tracking; recognised by judges for hardware-software co-design approach.
